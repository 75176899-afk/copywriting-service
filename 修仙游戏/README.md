# 修仙放置手游 - 游戏说明
## 🎮 游戏简介
一款基于HTML5/JavaScript开发的放置类修仙游戏，玩家通过修炼、探索、突破境界来提升实力，最终飞升仙界。
## 📁 文件结构
D:\修仙游戏
├── index.html          # 游戏主页面
├── game-config.js      # 游戏配置文件
├── game-save.js        # 游戏保存系统
├── skill-system.js     # 技能系统
├── world-map.js        # 世界地图系统
├── monthly-system.js   # 月卡/VIP系统
└── README.md           # 本说明文档
## 🚀 快速开始
1. 将所有文件保存到 `D:\修仙游戏\` 文件夹
2. 双击 `index.html` 用浏览器打开游戏
3. 开始你的修仙之旅！

🐛 常见问题
Q: 游戏数据会丢失吗？
A: 数据保存在浏览器本地存储中，清除浏览器数据会丢失存档。
Q: 如何重置游戏？
A: 在浏览器开发者工具中清除localStorage，或使用游戏内的重置功能。
Q: 支持离线游玩吗？
A: 支持！所有文件都在本地，无需网络连接。
Q: 如何修改游戏参数？
A: 编辑 game-config.js 文件中的配置项。
